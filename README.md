# Tic Tac Toe

A simple and interactive **Tic Tac Toe game** built using HTML, CSS, and JavaScript. The project allows two players to play the classic game with a clean and responsive interface.

## 🚀 Live Demo

[Play Tic Tac Toe](https://tictactoe-game-wine.vercel.app/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Two-player gameplay
- Win and draw detection
- Game reset functionality
- Interactive and responsive UI
